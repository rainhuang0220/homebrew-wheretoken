# homebrew-wheretoken

Homebrew tap for [whereToken](https://github.com/rainhuang0220/whereToken). Installs the GitHub Release binary for your CPU (macOS and Linux, amd64 or arm64). Does not require Go.

```bash
brew tap rainhuang0220/wheretoken
brew install wheretoken
```

Pinned to **v0.1.1**. GitHub Release binaries are currently unsigned.
